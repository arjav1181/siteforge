# `siteforge 3d`

```bash
siteforge 3d --list
siteforge 3d particle --dir src/components
```

Presets: `particle` (starfield + mouse parallax + scroll fade), `terrain`
(animated wireframe landscape, scroll camera), `shapes` (floating chrome
geometry, studio lights), `orb` (custom GLSL gradient blob),
`model` (GLB viewer: auto-rotate, drag orbit, full scroll spin).

Then: `npm install three @types/three`. Render full-bleed inside a relative
hero (`absolute inset-0` is baked in — put content in a `relative z-10`
sibling). Components cap DPR at 1.5 and dispose on unmount. `model` reads
`/models/hero.glb` by default — drop your file in `public/models/`.
